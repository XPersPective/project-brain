# ADR-002 — Public release and installed agent upgrades

## Status
Accepted

## Context
The user expanded the audit into publishing the verified version on GitHub and
supported public plugin directories, and updating this machine's agents through Skill Manager.

## Decision
Release 2.1.0, keeping schema 4. Publish the existing repository/marketplaces and
a distributable archive. Use Skill Manager's existing central library and target
links rather than independent manual copies. Submit official listings if access
and provider requirements permit; never equate GitHub distribution with catalog approval.

## Rationale
One maintained skill source serves the existing distribution formats. Native
manager operations preserve registration and deployments; content hashes verify updates.

## Alternatives
- Copy files manually: bypasses manager state and increases drift.
- Treat a GitHub push as directory approval: inaccurate; providers have separate review.

## Consequences
- PB-001 through PB-003 remain completed audit work.
- PB-004 handles release checks/push, PB-005 local upgrades, PB-006 directory submissions.
- Login, identity verification or provider review may need the user or external approval.
- No unrelated skill, credential or agent preference changes are authorized.
